# Uber Clone (MERN)

## Setup

1. **Backend**
   ```bash
   cd backend
   npm install
   npm run dev
   ```
   Ensures MongoDB is running.

2. **Frontend**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

## Features implemented
- User & Captain Auth (JWT, Cookies)
- Registration & Login
- Ride Calculation (Fare, Distance via Google Maps)
- Project Structure (Modules, Services, Controllers)
